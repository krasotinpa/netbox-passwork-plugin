# netbox-passwork

Плагин NetBox, который показывает секреты из Passwork на страницах объектов NetBox
и ведёт аудит обращений к ним.

## Язык

**Секрет**:
Запись в Passwork (пароль с сопутствующими полями). Плагин её не хранит — только показывает.
_Избегать_: пароль, item

**Привязка**:
Связь «объект NetBox ↔ секрет». Данные плагина, а не объекта; живёт независимо от объекта.
_Избегать_: binding, ссылка, связка

**Целевой объект**:
Объект NetBox (устройство, виртуальная машина или сервис), к которому привязан секрет.
_Избегать_: связанный объект, target

**Осиротевшая привязка**:
Привязка, чей целевой объект удалён из NetBox. Её секрет читать нельзя никому;
удалить её может любой обладатель права плагина на удаление привязок.
_Избегать_: битая привязка, stale binding

**Объектная проверка**:
Правило доступа: любая операция с секретом требует права видеть целевой объект
с учётом ограничений NetBox (ObjectPermission), сверх прав самого плагина.
_Избегать_: object-level check, проверка по объекту

**Права плагина**:
Собственные разрешения плагина (видеть секреты, раскрывать, привязывать, удалять привязки,
читать журнал). Отвечают на вопрос «что можно делать», объектная проверка — «с чем».
_Избегать_: пермишены, plugin permissions
